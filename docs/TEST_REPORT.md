# テスト結果（2026-10-27）

## 実施環境

- 教材テスト: Node.js 22 ＋ PostgreSQL 16.15（ローカル）
- ブラウザテスト: Chromium（Playwright 1.63）。アプリを `?engine=bridge` で起動し、SQLはローカルの PostgreSQL 16 で実行
- 開発環境の通信制限により npm レジストリと CDN（jsdelivr）に接続できなかったため、**PGlite（WASM）本体を読み込んだ状態での動作は、この環境では確認できていません**。PGlite は PostgreSQL 17 系で、教材で使うSQL（`pg_input_is_valid` など PostgreSQL 16 以降の機能を含む）は互換です。初回起動時に確認してください（起動しない場合は画面に原因と対処が表示されます）。
